# Pflichtenheft

## Ziel

Die Software unterstützt den gesamten Turnierablauf vom Import der Teams
bis zur Siegerehrung.

## Version 1.0

### Öffentliche Website

-   Home
-   Anmeldung (Microsoft Forms)
-   Spielregeln
-   Datenschutz
-   Live

### Live

-   Gruppen
-   Ranglisten
-   Spielplan
-   Geplante Startzeit
-   Board
-   Resultate
-   KO-Baum

### Admin

-   Login
-   Dashboard
-   CSV-Import
-   Teamverwaltung
-   Gruppen auslosen
-   Spielplan generieren
-   Geplante Startzeit bearbeiten
-   Board ändern
-   Resultate erfassen
-   KO generieren
-   Testmodus

## Bedienprinzip

Jede Standardaufgabe soll in maximal 2--3 Klicks erledigt werden.
