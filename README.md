# Cornhole Cup Boltigen – GitHub Pages Website

Statische Website für den Cornhole Cup Boltigen im Stil des Flyers/Headers.

## Inhalt

- `index.html` – Website-Inhalt
- `style.css` – Design im Flyer-Stil und mobile Darstellung
- `script.js` – Menü und dezente Animationen
- `assets/` – Header, Logo, Musikgesellschaft-Logo, QR-Code und Social-Bild

## Veröffentlichung mit GitHub Pages

1. Neues GitHub-Repository erstellen, z. B. `cornhole-cup-boltigen`.
2. Alle Dateien aus diesem Ordner ins Repository hochladen.
3. In GitHub öffnen: `Settings` → `Pages`.
4. Unter `Build and deployment` auswählen: `Deploy from a branch`.
5. Branch: `main`, Ordner: `/root` wählen.
6. Speichern.

Danach ist die Seite unter einer Adresse wie dieser erreichbar:

`https://DEIN-GITHUB-NAME.github.io/cornhole-cup-boltigen/`
